Pythagoras

A modular, workflow-driven data science environment built with Shiny for Python.

Welcome to Pythagoras



Pythagoras is a sequence of “cards” each of which deals with some aspect of data analysis and modeling.

Each card has a set of standard features:

  • Can be made full screen
  • Can be reordered by dragging their handles
  • Has a flip side with additional information
  • Provides an explanation of its purpose
  • Has a sidebar with card-specific settings
  • Can reveal its code (for use in notebooks)
  • Will guide you through the use of the card

The workflow (i.e. the sequence of cards) allows

  • Cards can be added and removed
  • Data to flow from card to card sequentially
  • A workflow to be saved and restored

The variables are assigned roles that determine how downstream cards will utilize them.

  • Target: The feature you seek to predict
  • Predictor: The common features of observations
  • Identifier: The observation’s unique reference
  • Partition: The pre-determined test/train allocation
  • Weighting: An observation importance weighting
  • Stratifier: The features that organize observations into functional groups
  • Treatment: A causal feature that is being investigated
  • Sensitive: A observational feature that can be assessed for fairness
  • Geometry: A feature that records geographic information
  • Sequence: A feature that dictates the ordering of observations

Everything runs within your browser - there is no installation. There are three running styles:

  1. Running locally under shinylive.
  2. Running a client browser remotely from a shiny server.
  3. Running the code locally as both server and client.

Pythagoras is the scaffold that holds the cards together.
