Learned imputation

A Pythagoras card

Nick Ward

🧭 Introduction

The goal of this card is to explore learned imputation (i.e. statistical imputation) as a means of resolving any remaining or future missing values. Three types of imputation are explored in this card:

  1. Median or Mode Simple imputation (Median for numeric, datetime, and ordinal variables and Mode for categorical variables)
  2. Nearest neighbors K-nearest neighbors imputation (cannot process categorical variables)
  3. Iterative prediction Multiple imputation by chained equations (M.I.C.E) (cannot process categorical variables)

Notes:

  • The last two employ all the (other) predictors to predict the missing values.
  • Only Predictors (variables of role = predictor) play any part in imputation.
  • The first method (Median or Mode) only needs to consider a single variable at a time.
Variable type Median or Mode Nearest neighbors Iterative prediction
Numeric Median Native Native
Datetime Numeric timestamp representation Numeric representation Numeric representation
Ordered category Median ordinal code Ordinal encoding and rounding Ordinal encoding and rounding
Nominal category Most frequent Mode fallback Mode fallback
String/boolean Most frequent Mode fallback Mode fallback
Cyclic, List, Geometry N/A N/A N/A

Ideally, the predictor variables are independent of each other and cannot assist in predicting a missing value. Any performance improvement over simple imputation intrinsically exploits predictor dependencies. If KNN and Iterative imputations are not significantly better than simple imputation, then stick with simple imputation.

Observations weightings, if supplied, are not utilized in the imputations.

🏞️ Front

The card’s front shows a bar chart of missing value counts before and after any imputation.

🔄 Flip side

The back of the card gives an assessment of the quality of the imputation. Statistics are tabled for each variable imputed.

The imputation performance table shows columns: Predictor, Data type, Number missing, Method-used, Metric, Score, Random-baseline score, Improvement and Status The random-baseline score is based on a metric assessed using only randomly guessed values. If the percentage improvement of the score exceeds the improvement-threshold, the imputation is deemed “Strong”. An improvement of zero means the imputation is no better than guessing.
