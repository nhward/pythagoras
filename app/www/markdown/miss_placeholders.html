Missing Values Placeholders

A Pythagoras card

Nick Ward

🧭 Introduction

A Missingness Heat-map is a visual tool for exploring tabular data. It highlights missing values and also flags candidate missing-value placeholders (e.g. -99, –, N/A). These candidates are configured in the sidebar and are typically data-type specific.

Placeholders = values used to stand in for “no data” when a value is required e.g. integers: -99, -999; floats: -99.0; strings: –, N/A; date-times: 0001-01-01.

The any buttons in the footer allow any named placeholders to be converted to missing values throughout the dataset.

Click here for a fully expanded discussion of missing values.

🏞️ Front

The card’s front shows a heat-map chart of potential placeholders, as well as missingness. Buttons allow the substitution of each potential placeholder.

🔄 Flip side

The back of the card tabulates the count of each placeholder per variable.

⚙️ Settings

Use the Tour Guide button to learn about the settings of this card.

🎯 Goals

  1. Primary: Help you verify whether candidate placeholders truly represent missingness (a domain-aware judgment).
  2. Secondary: Make it easy to fix the data. For each detected placeholder, the card provides a button to replace those values with an unambiguous missing value. The chart and table refresh to verify the efficacy of the operation.

All cards downstream of this card will receive any changes enacted by this card. At most, these changes will produce additional missing values.
