🧭 Introduction

This card displays the events that Pythagoras has logged. Initially, the most recent are at the top of the data-grid. Reordering the rows can change this. Many of the events are recorded against specific “loggers” e.g. data_import - which signifies it was generated by a data-import card. The <javascript> logger records events generated within the browser.
The event importance levels are:

  • DEBUG
  • INFO
  • WARNING
  • ERROR
  • CRITICAL

🔄 Flip side

There is no flip-side

🎯 Goals

This card does not require a data set. This card does not change any dataset. Any cards downstream of this card will receive the upstream version of the data.
